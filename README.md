# AutoChallenge 定时挑战插件

- 作者: 淦
- 定时发起小挑战，完成获得奖励。支持击杀怪物、收集物品、生存时间、钓鱼四种挑战类型，所有挑战内容均可通过配置文件自定义。

## 指令

| 语法                          | 权限             | 说明                                                                             |
|-------------------------------|------------------|----------------------------------------------------------------------------------|
| `/cjoin`                      | `challenge.join` | 参与当前进行的挑战                                                                  |
| `/cm list`                    | `challenge.admin`| 查看所有挑战配置列表                                                                  |
| `/cm start <编号>`             | `challenge.admin`| 手动开始指定编号的挑战（编号从0开始）                                                  |
| `/cm stop`                    | `challenge.admin`| 强制结束当前进行中的挑战                                                                |
| `/cm reload`                  | `challenge.admin`| 重载配置文件（修改配置后需执行此命令）                                                    |

## 权限

| 权限节点           | 默认组   | 说明                     |
|--------------------|----------|--------------------------|
| `challenge.join`   | `default`| 允许玩家参与挑战          |
| `challenge.admin`  | `owner`  | 允许管理员管理挑战        |

## 配置

> 配置文件位置: `tshock/AutoChallenge/配置.json`

```json5
{
  "插件开关": true,                // 插件总开关
  "挑战间隔(秒)": 600,              // 两次自动挑战之间的间隔时间（秒）
  "挑战列表": [
    {
      "挑战名称": "史莱姆猎人",       // 挑战显示名称
      "挑战类型": "击杀怪物",         // 可选：击杀怪物、收集物品、生存时间、钓鱼
      "目标": "史莱姆",             // 目标名称（支持模糊匹配）
      "数量要求": 10,               // 需要完成的数量
      "持续时间(秒)": 300,           // 挑战持续时间（秒）
      "奖励": {
        "奖励类型": "物品",           // 可选：物品、Buff、命令
        "标识符": "71",              // 物品ID / BuffID / 命令文本
        "数量": 5                    // 数量或持续时间（Buff固定3600秒）
      },
      "进度条件": "肉前"             // 可选，世界进度限制（肉前、肉山、三王、月总等）
    }
  ]
}
```
## 挑战类型说明
- **击杀怪物**：击杀名称包含“目标”的怪物（如“史莱姆”会匹配所有史莱姆变种）。

- **收集物品**：背包中拥有指定名称的物品达到数量要求时自动完成（不消耗物品）。

- **生存时间**：在挑战持续期间存活指定秒数，死亡则失败。

- **钓鱼**：钓起名称包含“目标”的物品（“任何”会匹配所有带“鱼”字的物品）。

## 奖励类型说明
- **物品**：通过“标识符”指定物品ID（如 `71` 为金币），给予指定数量。

- **Buff**：通过“标识符”指定Buff ID（如 `5` 为铁皮），持续3600秒。

- **命令**：执行控制台命令，`{Player}` 会被替换为玩家名（如 `group add {Player} vip`）。

## 进度条件
- 支持的值参考 Utils.CheckCond 中定义的条件，常用值包括：`肉前`、`肉山`、`三王`、`世纪之花`、`石巨人`、`月总`、`血月`、`雨天` 等。

- 若字段为空字符串 `""` 或缺失，则该挑战始终可用（无进度限制）。
